# Шахта WXS Game

GitHub Pages публикует игру из `main` по адресу
https://wxs-game.github.io/wxs-release/minecraft/.

В личном чате с @wxsgame игра должна открываться кнопкой «Шахта» у администратора
`6130985988`. Доступ к балансу и ставкам требует подписанного Telegram initData
основного бота. Обычный браузер показывает экран входа.

## Команда бота

`server/bot-main.patch` добавляет обработчик точной команды `/mimecraft` для этого
администратора и основного бота. `main.py` запускается на отдельном сервере.
В его рабочей копии проверьте и примените патч, затем перезапустите процесс бота
обычным для этого сервера способом.

```sh
git apply --check /path/to/wxs-release/minecraft/server/bot-main.patch
git apply /path/to/wxs-release/minecraft/server/bot-main.patch
python -m py_compile main.py
```

После перезапуска пошлите `/mimecraft` в личный чат с @wxsgame. Бот должен ответить
кнопкой «Открыть шахту».

## Проверка

Frontend статический. Из корня репозитория запустите
`python -m http.server 8000 --bind 127.0.0.1` и откройте
`http://127.0.0.1:8000/minecraft/?demo=1`. В демо используется учебный баланс.

Серверная миграция `../supabase/migrations/20261122203007_wxs_voxel_mine.sql` использует
функции Telegram-аутентификации и баланса проекта WXS. Руды рассчитываются
на сервере, а повтор запроса с тем же идентификатором возвращает прежний исход.
RTP 97,5% рассчитан без округления выплаты до центов. ТНТ выпадает с шансом 10%.
